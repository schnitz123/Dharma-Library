ཕན་གདགས་པར་བྱ་བའི་རིགས་སུ་གནས་པར་རབ་ཏུ་ཕྱེ་བ། འབྲས་བུའི་མཚན་ཉིད།
**Definition:** That distinguished by abiding in the class of receiving benefit.

རིགས་གནས་སྨོས་པ་ལ་དགོས་པ་ཡོད་དེ། བྲལ་འབྲས་བསྡུ་བའི་ཆེད་ཡིན་པའི་ཕྱིར།
There is a purpose in saying "abiding in the class": In order to include separation results.

**Divisions:** དེ་ལ་ལྔ་ཡོད་དེ།
1. [[Abhidharma/Fruitional result\|Fruitional result]] རྣམ་སྨིན་གྱི་འབྲས་བུ།
   Result of [[Abhidharma/Fruitional cause\|Fruitional cause]]
2. [[Abhidharma/Causally concordant result\|Causally concordant result]] རྒྱུ་མཐུན་གྱི་འབྲས་བུ།
   Result of [[Abhidharma/Homogeneous cause\|Homogeneous cause]] and [[Abhidharma/Omnipresent cause\|Omnipresent cause]]
3. [[Abhidharma/Separation result\|Separation result]] བྲལ་བའི་འབྲས་བུ།
   Not the result of any cause because it is uncompounded རྒྱུ་གང་གི་ཡང་འབྲས་བུ་མ་ཡིན་ཏེ་འདུས་མ་བྱས་ཡིན་པའི་ཕྱིར།
4. [[Abhidharma/Agentive result\|Agentive result]] སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ།
   Result of both [[Abhidharma/Simultaneously arising cause\|Simultaneously arising cause]] and [[Abhidharma/Concomitant cause\|Concomitant cause]]
5. [[Abhidharma/Empowering result\|Empowering result]] བདག་འབྲས།
   Result of [[Abhidharma/Acting cause\|Acting cause]]

ཁ་ཅིག །བྲལ་འབྲས་དངོས་མེད་ཡིན་ཟེར་ན། མི་འཐད་དེ། བྱེ་བྲག་སྨྲ་བའི་སྐབས་འདིར་གཞི་གྲུབ་ན་དངོས་པོ་ཡིན་དགོས་པའི་ཕྱིར།
If someone says "Separation results are non-things", then this is incorrect because in the context of Vaibhashika, if it is an established-basis, then it is necessarily a thing.

**Relationships:**
- Agentive results and empowering results are not mutually exclusive because if it is a compounded phenomenon, then it is necessarily both
  སྐྱེས་བུ་བྱེད་འབྲས་དང་བདག་འབྲས་མི་འགལ་ཏེ། འདུས་བྱས་ཡིན་ན་དེ་གཉིས་ཀ་ཡིན་དགོས་པའི་ཕྱིར།
- Fruitional, causally concordant, agentive, and empowering results are not mutually exclusive because if it is a fruition, then it is necessarily all four
  རྣམ་སྨིན་རྒྱུ་མཐུན་གཉིས། སྐྱེས་བདག་གཉིས་རྣམས་མི་འགལ་ཏེ། རྣམ་སྨིན་ཡིན་ན་དེ་བཞི་ཀ་ཡིན་དགོས་པའི་ཕྱིར། 
- Separation results are mutually exclusive with all four because if it is that, then it is necessarily not any of those four
  བྲལ་འབྲས་བཞི་ཀ་དང་འགལ་ཏེ། དེ་ཡིན་ན་བཞི་པོ་གང་རུང་མ་ཡིན་དགོས་པའི་ཕྱིར། 
 
བྲལ་འབྲས་འབྲས་བུ་ཡིན་ཏེ། བསྟན་བཅོས་ལས། འབྲས་བུ་གང་ཞེ་ན། འདུས་བྱས་རྣམས་དང་སོ་སོར་བརྟགས་པའི་འགོག་པའོ། །ཞེས་གསུངས་པའི་ཕྱིར། 
Separation results are results because a treatise says "What is a result? Compounded phenomena and analytical cessations."
